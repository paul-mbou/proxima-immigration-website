# Proxima Immigration

**Marketing site for Proxima SARL, a Canadian immigration practice in Douala.**
Site vitrine : expertises (résidence, études, travail, famille), préparation TCF / TEF, et prise de contact.

![Accueil en ligne](docs/portfolio/home.png)

![Expertises en ligne](docs/portfolio/expertises.png)

![TCF / TEF en ligne](docs/portfolio/tcf-tef.png)

![Contact en ligne](docs/portfolio/contact.png)

**Live:** [proxima-immigration.vercel.app](https://proxima-immigration.vercel.app/)

## What it does

- Home with the practice’s positioning
- One page per expertise, with the documents and the steps of a file
- TCF / TEF page
- About and contact, including WhatsApp

Copy, photography and phone numbers belong to the practice. This repository is the site that publishes them.
